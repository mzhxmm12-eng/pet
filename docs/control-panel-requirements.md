# 桌面宠物控制面板需求文档

## 目标

在现有 Windows 桌宠基础上新增一个简单控制面板，用于选择宠物、调整宠物大小和行为参数，并为后续新增多只猫、狗狗宠物和自定义宠物导入预留结构。

## 使用入口

- 宠物右键菜单：新增「打开控制面板」或「设置」入口。
- 系统托盘菜单：新增「打开控制面板」入口。
- 两个入口打开同一个控制面板窗口，避免重复设置逻辑。

## 页面结构

控制面板采用 Tab 结构：

- 猫窝：第一版可用，用于选择猫咪和调整设置。
- 狗窝：第一版仅展示占位状态「即将上线」，为后续狗狗宠物预留。

## 猫窝功能

### 宠物选择

- 展示当前可用猫咪列表。
- 每只猫使用卡片展示：预览图、名称、选中状态。
- 当前选中猫咪使用高亮边框和浅色背景。
- 预留「添加猫咪」入口，第一版可隐藏或置灰。

### 外观设置

- 宠物大小：调整桌宠显示缩放。
- 透明度：调整桌宠窗口透明度，第一版可选做。
- 置顶显示：控制宠物是否始终置顶，第一版可选做。

### 行为设置

- 移动速度：控制走路位移速度。
- 互动频率：控制逗猫触发冷却和自动互动强度。
- 点击穿透：开启后减少工作时误点宠物。
- 文件投喂：控制是否允许拖拽文件投喂。
- 投喂前确认：控制投喂前是否弹出确认框。

### 预览区域

- 展示当前选中宠物的预览图或 idle 动画。
- 调整宠物大小时可同步展示预览效果。
- 后续可扩展动作预览：待机、走路、睡觉、玩耍、吃东西。

### 操作区

- 显示宠物运行状态：运行中、暂停中、隐藏中。
- 重置位置：将宠物移动回默认位置。
- 应用设置：保存设置并应用到当前宠物。
- 暂停/继续：控制宠物行为和动画。

## 狗窝功能

第一版仅做占位：

- 展示「狗狗宠物即将上线」。
- 不提供真实狗狗选择和设置。
- 后续狗狗上线后复用与猫窝一致的选择和设置结构。

## 数据要求

设置需要支持全局设置和宠物独立设置。

```json
{
  "activePetId": "orange_cat_builtin",
  "pets": {
    "orange_cat_builtin": {
      "scale": 2,
      "moveSpeed": 1,
      "interactionLevel": "medium",
      "opacity": 1,
      "left": 1200,
      "top": 720
    }
  },
  "global": {
    "clickThrough": false,
    "feedingEnabled": true,
    "confirmBeforeFeeding": true,
    "topmost": true
  }
}
```

宠物 manifest 需要继续保留：

- petId
- name
- species：cat 或 dog
- preview
- canvas
- hitArea
- animations

## MVP 范围

必须完成：

- 控制面板窗口。
- 猫窝 Tab。
- 狗窝占位 Tab。
- 当前猫咪选择卡片。
- 宠物大小调整。
- 移动速度调整。
- 互动频率调整。
- 点击穿透开关。
- 文件投喂开关。
- 投喂确认开关。
- 重置位置。
- 应用设置。
- 从宠物右键菜单打开。
- 从系统托盘菜单打开。

暂不完成：

- 在线宠物商店。
- 网站素材导入。
- 狗狗真实素材和行为。
- 多宠物同时运行。
- 动作编辑器。

## 验收标准

- 从宠物右键菜单和系统托盘都能打开控制面板。
- 选择猫咪后，当前宠物显示和设置能正确应用。
- 调整大小、移动速度、互动频率后，当前宠物行为发生变化。
- 点击穿透、文件投喂、投喂确认能正确保存并立即生效。
- 重启应用后保留上次选择的宠物和设置。
- 狗窝 Tab 可见但不可操作，不影响猫窝功能。
- 控制面板关闭后不退出桌宠主程序。
